Сначала появился проект на вм с файлами, а уже потом появился репозиторий

Просто сделать git clone в директорию, где уже есть файлы, Git не разрешит (он потребует, чтобы папка была пустой).
Чтобы объединить локальную директорию с существующим репозиторием из интернета и при этом не стереть свои файлы, я поступил следующим образом:

1: Сделал из папки локальный репозиторий
Зашел в свою директорию и выполнил следующие команды:
git init

2: Связал локальную директорию с репозиторием на github
Добавил адрес репозитория:
git remote add origin [https://github.com](https://github.com/dizzamer/golang-diary)

3: Скачал историю (без перезаписи файлов)
Теперь нужно забрать данные из интернета, но не сливать их с вашими файлами сразу. 
Пишем:
git fetch origin

4: Объединяю ветки
Теперь самое важное. Нам нужно связать вашу текущую ветку с веткой из интернета (обычно она называется main или master).
Можно проверить командой git remote show origin
Так как у моей папки и у репозитория в интернете разная история, Git по умолчанию выдаст ошибку. Чтобы обойти это, используйте специальный флаг --allow-unrelated-histories:

# Если ветка в интернете называется main:
git merge origin/main --allow-unrelated-histories

# Если ветка в интернете называется master:
git merge origin/master --allow-unrelated-histories

Что произойдет: Git скачает файлы из интернета в директорию. 
Если имена файлов не совпадают, они просто добавятся рядом с вашими. Если файлы называются одинаково, Git предложит вам разрешить конфликт (выбрать, какую версию оставить).

Шаг 5: Отправьте ваши файлы в интернет
Теперь, когда истории объединены, вы можете добавить свои локальные файлы, сделать коммит и отправить их на сервер:
git add .
git commit -m "Добавил локальные файлы проекта"
git push -u origin main  # (или master, в зависимости от имени ветки)


Примечание:
Если не получилось закомитить с первого раза
Шаг 1: Объедините локальную историю с GitHub
Запустите принудительное слияние независимых историй. Эта команда скачает README.md с сервера и аккуратно добавит его к вашим локальным файлам Go:
git merge origin/main --allow-unrelated-histories --no-edit

Шаг 2: Повторите отправку
После слияния папок отправьте итоговый результат на GitHub:
git push -u origin main --force
